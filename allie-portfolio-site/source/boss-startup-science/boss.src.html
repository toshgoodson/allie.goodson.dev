RoleUX/UI designer
TimelineJul 2022 – Mar 2023
FocusDesign system, academy, admin + data

BOSS Startup Science pairs pre-accelerator courses for founders with a database where investors, accelerators, and incubators find startups to back. As the only designer, I built the design system first, then designed the academy, the data-heavy tables, and the admin tools for the MVP.

01

Design system

Engineers and I needed one reference before anything else, so the system came first: a purple-led palette with ready-made text and background pairs, a type scale, spacing, shape, and elevation tokens, and every button and input state.

What changed

Looking back

Midway through, the company pivoted. What started as a learning platform for startups quickly became a way to match startups with investors by stage and interest. Building the design system first is what made that pivot easy, for me and for the devs. Speed sometimes won over polish, but the system kept the fast work consistent, and it’s the first thing I’d build again.
